RIVO STORE — WEBSITE FILES

HOW TO RUN
1. Extract Rivo_Store_Website.zip.
2. Open the folder in VS Code.
3. Open js/products.js.
4. Change RIVO_CONFIG.whatsappNumber to the real brand number in international format, without + or spaces.
   Example Egypt: 2010XXXXXXXX
5. Change the sample prices in RIVO_PRODUCTS to your actual prices.
6. Open index.html with Live Server.

FILES
- index.html: Home page / collection
- product.html: Product detail and order form
- css/style.css: Design and responsive layout
- js/products.js: Product info, prices, sizes and WhatsApp settings
- js/app.js: Product cards on home page
- js/checkout.js: Product detail, form validation and WhatsApp order message
- images/: Your uploaded logo and hoodie images

IMPORTANT
The prices are sample prices and should be edited before publishing.
The WhatsApp number is intentionally a placeholder. Orders won't open until you enter the brand's real number.
This is a front-end site: it opens WhatsApp with the filled order; it does not save orders in a database.
